# 모으기: 수집기와 서버 사이의 꼴

파이썬 수집기(`collector/`)가 정리한 줄을 서버에 넘길 때의 약속이다. 수집기는 이 문서만 보고 붙는다.
이 문서와 코드가 다르면 코드(`src/contract/tools/collect.ts`)가 맞다. 고칠 때는 둘을 함께 고친다.

- 상태(2026-10-13): 서버의 받는 쪽과 수집기를 만들었고, 수집기로 12개 출처를 로컬 서버에 실제로 보내 봤다(잰 수는 [COLLECTOR.md](COLLECTOR.md) 3절).

## 1. 누가 무엇을 하나

| 하는 일 | 누가 |
|---|---|
| 파일 받기, 글자 인코딩 판별, 출처별 칸 이름 맞추기, 숫자·단위 꼴 정리 | 수집기 |
| 줄의 꼴 검사, 중복 가르기, 표시 붙이기, 저장 | 서버 |
| 줄 → 초안(값 맞추기와 검사) | 서버(본체의 맞추기·따지기 그대로) |

수집기가 중복을 미리 빼도 된다. 다만 맞고 틀림은 서버가 정한다(3절의 식).

## 2. 보내기: `POST /api/imports`

- 주소: `<서버 주소>/api/imports`
- 헤더: `Content-Type: application/json`, `X-Workspace: <작업 공간 번호>`
  - 번호 없이 보내면 서버가 새 공간을 만들고 응답의 `workspace`에 돌려준다. 다음 요청부터 그 번호를 헤더에 넣는다.
  - 화면에서 보려면 브라우저가 쓰는 공간 번호(화면 맨 위에 보인다)를 수집기에 넘겨 그 번호로 보낸다.
- 한 번에 500줄까지, 본문은 3MB까지다. 더 많으면 나눠 보낸다. 출처가 다르면 요청도 나눈다(요청 하나 = 출처 하나).
- 본보기 공간(`00000000-0000-0000-0000-000000000000`)에는 쓸 수 없다(403).

```json
{
  "source": {
    "id": "sample-outdoor-2026",
    "name": "가상 기관 옥외광고 현황",
    "url": "https://example.org/data/outdoor.csv",
    "license": "이용 조건을 적는다(예: 출처 표시 조건)",
    "fetchedAt": "2026-10-12T03:00:00Z"
  },
  "rows": [
    {
      "line": 3,
      "kind": "전광판",
      "name": "홍대입구역 9번 출구 전광판",
      "region": "서울 마포구",
      "address": "서울 마포구 양화로 160",
      "subway_line": "2호선",
      "station": "홍대입구역",
      "media_type": "LED 전광판",
      "width_m": 7,
      "height_m": 12,
      "quantity": 1,
      "lat": 37.557,
      "lng": 126.924,
      "operator": "가상 운영 기관",
      "raw": { "명칭": "홍대입구역 9번 출구 전광판", "규격": "7m x 12m" },
      "flags": ["unit_assumed"]
    }
  ],
  "collector": { "unreadable": 2, "duplicates": 1 }
}
```

### 출처(`source`) — 전부 꼭 있어야 한다

| 칸 | 꼴 | 뜻 |
|---|---|---|
| `id` | 소문자·숫자·줄표, 60자까지 | 수집기의 출처 목록에 적힌 짧은 번호 |
| `name` | 글자 200자까지. 제어 글자(줄바꿈, NUL)가 있으면 400 | 자료 이름과 낸 기관 |
| `url` | 주소. 제어 글자가 있으면 400 | 받은 곳 |
| `license` | 글자 200자까지. 제어 글자가 있으면 400 | 이용 조건. 모르면 보내지 않는다(조건을 모르는 자료는 쓰지 않는다) |
| `fetchedAt` | ISO 8601, 시간대 포함 | 자료를 받은 시각 |

### 줄(`rows[]`)

| 칸 | 꼴 | 뜻 |
|---|---|---|
| `line` | 1 이상 2,147,483,647 이하의 정수. **꼭 있어야 한다** | 출처 파일 안의 줄 번호(머리줄 다음이 1). 더 큰 수는 그 줄만 `BAD_ROW` 다 |
| `raw` | 칸 이름 → 글자·수·참거짓·null. **꼭 있어야 한다** | 원래 줄 그대로. JSON 글로 4,000자까지 |
| `kind` | 글자 | 종류. 자료에 적힌 큰 갈래 |
| `name` | 글자 | 이름 |
| `region` | 글자 | 지역(시·구·동) |
| `address` | 글자 | 주소 |
| `subway_line` | 글자 | 호선 |
| `station` | 글자 | 역 |
| `media_type` | 글자 | 매체 종류 |
| `width_m`, `height_m` | 0 보다 큰 수 | 가로·세로. **m 단위의 수**로 준다 |
| `quantity` | 0 이상의 정수 | 수량(면, 기) |
| `lat`, `lng` | 수(−90~90, −180~180) | 좌표. 자료에 있을 때만. 주소로 만들어 내지 않는다 |
| `operator` | 글자 | 운영 기관 |
| `flags` | 아래 둘 가운데 | 수집기가 붙이는 표시 |

- 글자 칸은 200자까지다. 없는 값은 `null`로 주거나 칸을 뺀다. 빈 글자(`""`)는 받지 않는다.
- 숫자는 숫자로 준다. `"7.5"`(글자), `"7m"`는 받지 않는다. 단위를 떼고 m로 바꾸는 것까지가 수집기의 일이다.
- 표에 없는 칸 이름이 있으면 그 줄은 받지 않는다(값이 조용히 버려지지 않게).
- 가격 칸은 없다. 설치 현황 자료에는 가격이 없고, 지어내지 않는다.
- 수집기가 붙일 수 있는 표시: `encoding_guessed`(인코딩을 짐작해 읽었다), `unit_assumed`(값에도 칸 이름에도 단위가 안 적혀 그 출처의 기본 단위로 읽었다. 기본 단위는 수집기의 출처 목록에 사람이 적은 mm·cm·m 가운데 하나다).

### 수집기가 스스로 뺀 줄(`collector`) — 선택

| 칸 | 뜻 |
|---|---|
| `unreadable` | 수집기가 읽지 못해 보내지 않은 줄 수 |
| `duplicates` | 수집기가 같은 파일 안의 중복으로 보고 보내지 않은 줄 수 |

서버는 이 수를 세지 못한다. 받은 그대로 묶음에 적어 화면에 낸다. 한 출처를 여러 요청으로 나눠 보낼 때는 한 요청에만 싣는다(겹쳐 세지 않게).
둘 다 0 이상 2,147,483,647 이하의 정수다(더 크면 400). 파일 전체에서 뺀 수이므로, 수집기는 줄을 골라 보낼 때(`--limit`, `--skip-mark`) 이 칸을 싣지 않는다.

## 3. 중복 열쇠

같은 공간에 같은 열쇠는 한 건이다. "같은 위치 · 같은 규격"을 한 건으로 본다. 조각 일곱을 `|`로 잇는다.

```
위치(주소, 없으면 지역) | 호선 | 역 | 매체 종류 | 가로 | 세로 | 이름
```

- 글자 조각: 유니코드 NFKC로 맞추고, 소문자로 바꾸고, 빈칸(탭·줄바꿈 포함)을 전부 뗀다.
- 수 조각: 소수 둘째 자리로 반올림한 뒤 필요 없는 0을 뗀다(`7` → `7`, `7.004` → `7`, `7.25` → `7.25`).
- 없는 조각은 빈 글자다.
- 이름 조각은 **위치와 역이 모두 비었을 때만** 넣는다. 그 밖에는 빈 글자다.
- 출처는 열쇠에 넣지 않는다. 다른 출처가 같은 자리를 적었으면 중복이다.

| 줄 | 열쇠 |
|---|---|
| 위의 보기 줄 | `서울마포구양화로160\|2호선\|홍대입구역\|led전광판\|7\|12\|` |
| 같은 줄에서 주소가 없을 때 | `서울마포구\|2호선\|홍대입구역\|led전광판\|7\|12\|` |
| 이름 "가 전광판"만 있을 때 | `\|\|\|\|\|\|가전광판` |

파이썬에서는 `unicodedata.normalize("NFKC", s).lower()` 뒤 `re.sub(r"\s+", "", …)`로 같은 글자 조각이 나온다.
수 조각은 자바스크립트의 `String(Math.round(v * 100) / 100)`과 같아야 한다(`7.0` → `"7"`).
파이썬의 `round`는 반올림 규칙이 다르므로(짝수 쪽으로) `math.floor(v * 100 + 0.5) / 100`으로 세고, 정수면 `.0`을 떼어 적는다.
수집기 시험에 위 표의 세 줄을 그대로 넣어 둔다.

## 4. 받는 답 (202)

```json
{
  "workspace": "작업 공간 번호",
  "batch": {
    "id": 12,
    "source": { "id": "sample-outdoor-2026", "name": "…", "url": "…", "license": "…", "fetchedAt": "…" },
    "received": 3, "new": 1, "duplicate": 1, "unreadable": 1,
    "collectorUnreadable": 2, "collectorDuplicates": 1,
    "receivedAt": "2026-10-12T03:00:05.000Z"
  },
  "items": [
    { "index": 0, "line": 3, "result": "new", "itemId": 101 },
    { "index": 1, "line": 4, "result": "duplicate", "itemId": 101 },
    { "index": 2, "result": "error", "code": "BAD_ROW", "message": "가로가 수가 아닙니다." }
  ]
}
```

- `index`는 요청의 `rows`에서 몇째인가(0부터).
- `received = new + duplicate + unreadable`. 한 줄이 틀려도 나머지는 들어간다.
- 줄의 오류 코드는 둘이다: `BAD_ROW`(줄의 꼴이 틀렸다), `LIMIT_EXCEEDED`(공간에 모아 둘 수 있는 줄 수 2,000에 닿았다).
- 요청 전체가 거절되는 경우(본문이 `{ "code", "message" }`):

| 상태 | 코드 | 언제 |
|---|---|---|
| 400 | `BAD_INPUT` | JSON이 아님, 출처가 빠졌거나 꼴이 틀림, 줄이 0개이거나 500개를 넘음 |
| 403 | `READ_ONLY_WORKSPACE` | 본보기 공간에 보냄 |
| 413 | `FILE_TOO_LARGE` | 본문이 3MB를 넘음 |
| 429 | `LIMIT_EXCEEDED` | 공간의 묶음 수 100에 닿음 |

수집기가 끝에 찍을 수: 출처 수, 서버가 받은 줄(`received`), 새 줄(`new`), 중복(`duplicate` + 수집기가 뺀 것), 못 읽은 줄(`unreadable` + 수집기가 못 읽은 것). 초안이 된 줄 수는 `GET /api/imports`의 `totals.drafted`다.

## 5. 그 밖의 경로

| 경로 | 하는 일 |
|---|---|
| `GET /api/imports` | 받은 묶음 목록과 합계 |
| `GET /api/collected?sourceId=&flag=&drafted=yes\|no&q=&cursor=` | 모은 줄 목록(한 쪽 50건) |
| `POST /api/collected/:id/draft` | 줄 하나를 본체의 초안으로. 새 초안 201, 이미 만든 줄 200 |

줄을 초안으로 만들 때 LLM을 부르지 않는다. 줄의 값(이름, 역 또는 지역, 가로×세로)을 원문 표현으로 삼아 본체의 맞추기·따지기를 거친다.
가격이 없는 자료라 "필수 칸 빔" 표시가 붙어 검수함의 "확인 필요"로 간다. 사람이 값을 채워야 승인할 수 있다.

## 6. 지킬 것

- 수집이 허용된 공공 자료만 쓴다. robots.txt와 요청 간격을 지키고, 출처마다 이용 조건을 `license`에 적는다.
- 원자료는 저장소에 넣지 않는다(`collector/.cache`는 `.gitignore`에 있다). 저장소에는 받는 스크립트와 출처 목록만 둔다.
- 변경을 금지한 자료는 고친 판을 배포하지 않고 로컬에서만 쓴다.
- 이 자료는 설치 현황이지 판매 상품이 아니다. 화면과 문서에서 그렇게 적는다.
