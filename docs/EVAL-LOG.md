# 평가 기록 — 고친 것과 버린 것

- 한 번에 한 가지만 바꾸고, 연습 세트에서 건별 나아짐·나빠짐을 본 뒤 여기에 적는다. 버린 시도도 지우지 않는다.
- 연습 세트의 점수는 고칠 때 보는 숫자다. 내세우는 숫자로 이 문서 밖에 옮기지 않는다. `docs/EVALUATION.md`에는 안 여는 세트와 나란히 놓는 한 곳에만 "고칠 때 본 묶음"이라고 표시해 실었다. README에는 싣지 않는다.
- 안 여는 세트(`test`, `real`)는 파이프라인을 얼린 뒤 한 번 돌린다. 몇 번 돌렸는지는 `eval_runs` 표로 드러난다. `test`는 2026-10-13에 돌렸다(아래 "최종 측정").
- 기준과 지표의 뜻은 `docs/EVAL-SPEC.md`, 명령은 `docs/EVALUATION.md`의 "돌리는 법"에 있다.

### 시도 6 — 글자 칸에서 원문 표현이 값을 이름표·문장째 감싼 꼴이면 값을 싣는다
